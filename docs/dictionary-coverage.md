# Dictionary coverage and fallback

The local catalogue is curated from Satzivo's authored vocabulary and examples. It is the first lookup source and works offline. `npm run audit:dictionary` scans German text fields from all ten curriculum modules, exam materials, and practice activities. It counts exact validated lemmas/forms; it does not treat a similar-looking word as a match and it does not count online lookup as verified local coverage. The full report is written to `reports/dictionary-coverage.json`.

For a local miss, the server respects the selected interface language. Spanish lookups first query WiktAPI's Spanish Wiktionary edition filtered to German (`/v1/es/word/{word}?lang=de`); only Spanish-edition glosses are shown as Spanish. If that lookup has no German entry or no gloss, the existing English Wiktionary definition endpoint is queried as a clearly labeled secondary definition. The Spanish result never silently falls back into the Spanish field. English lookups use the English German-entry endpoint directly. This structured Spanish endpoint has partial coverage: it supplied Spanish glosses for tested words such as `Tisch`, `Wohnung`, `Flugzeug`, `Regen`, `Hausaufgabe`, and `Schlüssel`, while tested terms such as `Mietvertrag`, `Besucher`, `hoffen`, `Fahrrad`, and `besuchen` had no Spanish result. A missing Spanish result is displayed as “Traducción al español no disponible” with the English definition explicitly labeled in English, when available.

Requests run server-side with a three-second timeout, a descriptive User-Agent, six-hour positive and short negative/error in-memory caches, per-language cache keys, in-flight deduplication, and the existing limit of 30 uncached requests per client per minute. A valid no-entry response is distinguished from network failure. The fallback only includes article, plural, and part-of-speech fields when the structured source explicitly supplies them; it does not translate English glosses, infer a Spanish meaning from context, or generate a lemma/example. The selected German sentence is displayed as context, not used to manufacture a definition. External fallback entries are not currently saved as personal flashcards because the existing SQLite/Supabase saved-word schemas persist known catalogue IDs only; the modal disables that action rather than losing entry metadata or claiming cross-device persistence.

WiktAPI is a community service built from structured Wiktionary data; its API code is MIT-licensed and documented at [WiktAPI](https://wiktapi.dev/) and its [source repository](https://github.com/TheAlexLichter/wiktapi.dev). The lexical content remains Wiktionary data, attributed to the relevant Spanish or English Wiktionary entry and licensed CC BY-SA 4.0. Satzivo does not bulk-copy Wiktionary data into its authored catalogue. The English definition endpoint is Wikimedia REST API and requires a descriptive User-Agent; see [Wikimedia REST API policies](https://www.mediawiki.org/wiki/API:REST_API/Policies). WiktAPI is a community-hosted dependency without a documented availability guarantee in the reviewed docs; the local dictionary remains the offline path, and external failures are reported separately.

## Known limit

Local coverage is intentionally reported separately from online fallback. The audit is the measure of how much text works offline; its missing-term list is a concrete curation backlog. The 95% local coverage target is not claimed unless that report reaches it. Wiktionary's endpoint is experimental and only supplies what its page has actually structured; it cannot guarantee an entry or a Spanish translation for every word.
