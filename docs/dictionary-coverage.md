# Dictionary coverage and fallback

The local catalogue is curated from Satzivo's authored vocabulary and examples. It is the first lookup source and works offline. `npm run audit:dictionary` scans German text fields from all ten curriculum modules, exam materials, and practice activities. It counts exact validated lemmas/forms; it does not treat a similar-looking word as a match and it does not count online lookup as verified local coverage. The full report is written to `reports/dictionary-coverage.json`.

For a local miss, the server queries the experimental German definition endpoint on English Wiktionary. The request is server-side, has a three-second timeout, coalesces duplicate in-flight lookups, uses a short in-memory cache, sends a descriptive User-Agent, and is limited to 30 uncached lookups per client per minute. A network/HTTP failure is distinguished from a valid no-entry result. The fallback returns only German entries and available English glosses; it does not generate Spanish translations, article gender, plural, examples, or a lemma it cannot validate. The UI labels and links these glosses to the Wiktionary entry and CC BY-SA 4.0 license. External fallback entries are not currently saved as personal flashcards because the existing SQLite/Supabase saved-word schemas persist known catalogue IDs only; the modal disables that action instead of losing entry metadata or claiming cross-device persistence.

Wiktionary text is reusable under CC BY-SA 4.0 with attribution and share-alike obligations. Satzivo does not bulk-copy the dump into its proprietary catalogue. The Wikimedia REST API requires a descriptive User-Agent and is governed by Wikimedia's API usage and robot policies. See [Wiktionary CC BY-SA](https://en.wiktionary.org/wiki/Wiktionary:CC-BY-SA), [Wikimedia REST API policies](https://www.mediawiki.org/wiki/API:REST_API/Policies), and [the German definition endpoint overview](https://www.mediawiki.org/wiki/Wikimedia_REST_API).

## Known limit

Local coverage is intentionally reported separately from online fallback. The audit is the measure of how much text works offline; its missing-term list is a concrete curation backlog. The 95% local coverage target is not claimed unless that report reaches it. Wiktionary's endpoint is experimental and only supplies what its page has actually structured; it cannot guarantee an entry or a Spanish translation for every word.
