# Satzora

Preparación intensiva del Goethe-Zertifikat A2 para adultos: 80 lecciones y 1.200 actividades sobre 400 contextos originales, simulacros, vocabulario y progreso. Interfaz en español e inglés.

El proyecto está en [deutschdock](deutschdock/README.md).

```powershell
cd deutschdock
npm install
npm run dev
```
